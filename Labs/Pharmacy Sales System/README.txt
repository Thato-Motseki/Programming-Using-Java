20-Mark Question 1 — Pharmacy Sales System

A pharmacy wants a simple Java program to calculate customer purchases.

The following products are available:

Product No.	Product	Price (M)
1	Paracetamol	25.00
2	Cough Syrup	45.00
3	Vitamins	80.00
4	Pain Relief Gel	35.00
5	Allergy Tablets	30.00

Write a Java program that:

Stores the product numbers, names and prices using arrays.
Displays the available products.
Allows the customer to select a product.
Allows the customer to enter the quantity.
Validates that the product number is valid.
Validates that the quantity is greater than zero.
Calculates the cost of each purchase.
Keeps a running total of all purchases.
Allows the customer to purchase multiple products.
Uses 0 to indicate that the customer has finished shopping.
Applies a 10% discount if the total exceeds M300.
Displays the subtotal, discount and final amount.
